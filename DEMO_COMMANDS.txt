PART 3: TECHNICAL EXPLANATION (3 minutes)
──────────────────────────────────────────
Explain the system architecture and detection logic

Show and Explain:

1. ARCHITECTURE DIAGRAM
   ┌─────────────┐
   │  Webcam     │ ← Captures video
   │   (640x480) │
   └──────┬──────┘
          │
   ┌──────▼──────────────┐
   │  YOLOv8 Nano-Pose   │ ← Detects 17-point skeleton
   │  (30+ FPS on CPU)   │
   └──────┬──────────────┘
          │
   ┌──────▼───────────────────────┐
   │ Geometric Analysis:          │
   │ • Calculate torso angle      │
   │ • Check leg alignment        │
   │ • Measure bounding box       │
   │ → Classify: Stand/Sit/Lie    │
   └──────┬───────────────────────┘
          │
   ┌──────▼───────────────────────┐
   │ Motion Quality Analysis:      │
   │ • Track velocity over time    │
   │ • Calculate acceleration      │
   │ • Measure smoothness (variance)
   │ → Distinguish fall vs sleep   │
   └──────┬───────────────────────┘
          │
   ┌──────▼──────────────┐
   │  Decision Engine    │
   │  Standing:  θ > 70° │
   │  Sitting:   35-70°  │
   │  Sleeping:  θ < 30°, smooth
   │  Fall:      θ < 30°, jerky
   └──────┬──────────────┘
          │
   ┌──────▼──────────────┐
   │ Alert System:       │
   │ • Color overlay     │
   │ • Email notification
   │ • Audio alert      │
   └─────────────────────┘

2. DETECTION LOGIC

   Posture Classification (Using Geometry):
   ──────────────────────────────────────────
   • STANDING: Torso angle from shoulders/hips > 70° (upright)
   • SITTING:  Torso angle 35-70°, legs bent at knees
   • LYING:    Torso angle < 30°, body horizontal

   Motion Analysis (Using Temporal Patterns):
   ──────────────────────────────────────────
   For transitions to lying:
   
   IF acceleration < 200 AND smoothness < 100 THEN
       → SLEEPING (intentional, smooth descent)
   
   ELSE IF acceleration > 300 OR smoothness > 150 THEN
       → FALL (sudden impact, jerky motion)

3. KEY INNOVATIONS

   "Why this works better than other systems:"
   
   a) Motion Quality Matters
      └─ Don't just detect "lying down"
      └─ Analyze HOW they're lying (smooth vs jerky)
      └─ Eliminates false positives from napping
   
   b) Geometry-Based (No Training Data Needed)
      └─ Physics rules: "standing = angle > 70°"
      └─ Works without training on thousands of examples
      └─ Adaptable to different body types
   
   c) Real-Time Performance
      └─ 30+ FPS on CPU, works on edge devices
      └─ No GPU required (but optional for faster inference)
      └─ Alert triggers within 1-2 seconds

       - Falling: 400+

→ Solution: Stand fully in frame, ensure good lighting, face camera

→ Solution: Stay still for 1 second, poor lighting causes jitter

→ Solution: Acceleration threshold at 300 - can be tuned if needed

→ Solution: Close any other camera apps, check device permissions
